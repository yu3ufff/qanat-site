Privacy Policy for Qanat

Effective date: May 25, 2026

Qanat is a Chrome extension that generates synced Uyghur subtitles for YouTube videos by translating available YouTube caption data.

Summary

Qanat is designed to translate available YouTube captions into Uyghur and display them as a synced subtitle overlay on YouTube. Qanat does not sell user data, does not use user data for advertising, and does not track browsing activity outside of YouTube.

Data Qanat Processes

YouTube page information

Qanat runs on YouTube pages to detect when you are watching a video and whether captions are available. This may include the current YouTube page URL and video-related caption availability data.

Caption text

When a YouTube video provides captions, Qanat processes the caption text so it can translate the captions into Uyghur and display them in sync with the video. Qanat does not transcribe raw audio directly. It relies on caption data already available from YouTube, including manual captions or auto-generated captions when available.

Extension settings

Qanat stores your extension settings locally, such as whether the extension is enabled or disabled. These settings are stored using Chrome local extension storage.

How Qanat Uses Data

Qanat uses the data described above only to provide its subtitle functionality. Specifically, Qanat uses data to:

  • Detect supported YouTube video pages
  • Check whether captions are available
  • Retrieve and parse available caption data
  • Translate caption text into Uyghur
  • Display synced Uyghur subtitles on the YouTube video player
  • Remember whether Qanat is enabled or disabled

Translation Processing

Qanat sends caption text to Google Translate through translate.googleapis.com in order to translate available captions into Uyghur. The translated text is returned to the extension and displayed as subtitles on the YouTube page.

Qanat does not operate its own server for storing or processing captions.

Data Storage

Qanat stores extension settings locally in your browser, such as the enabled or disabled state of the extension. Qanat does not intentionally store YouTube captions, translated captions, video history, or browsing history on its own servers.

Data Sharing

Qanat does not sell, rent, or trade user data. Qanat does not share user data with advertisers. Caption text is sent to Google Translate only for the purpose of generating Uyghur translations.

Data Not Collected

Qanat does not collect:

  • Your name
  • Your email address
  • Your passwords
  • Your payment information
  • Your full browsing history
  • Your YouTube account credentials
  • Your private messages
  • Your personal files

Chrome Extension Permissions

storage

Used to save the extension’s enabled or disabled state locally in your browser.

activeTab

Used when you open the Qanat popup so the extension can communicate with the current active YouTube tab and apply your on/off preference.

YouTube host permissions

Used to detect YouTube video pages, access available caption data, and display the Uyghur subtitle overlay on the video player.

Google Translate host permission

Used to send caption text to Google Translate and receive Uyghur translations.

Limited Use Statement

Qanat’s use of data is limited to providing its single purpose: generating synced Uyghur subtitles for YouTube videos from available caption data. Qanat does not use user data for advertising, does not sell user data, and does not transfer user data except as necessary to provide the translation functionality described in this policy.

Security

Qanat uses HTTPS endpoints when communicating with Google Translate. Qanat does not require user accounts, passwords, API keys, or payment information.

Children’s Privacy

Qanat is not designed to knowingly collect personal information from children.

Changes to This Policy

This Privacy Policy may be updated from time to time. If changes are made, the updated policy will be posted with a new effective date.
